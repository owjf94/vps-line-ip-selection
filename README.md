## 线路和IP类型，先搞懂这两件事

### 线路决定延迟和稳定性

**CN2 GIA**：电信的优质线路，三网回程走CN2，延迟低、晚高峰稳定，适合建站和需要长期在线的业务。ZoroCloud的香港CN2GIA方案，双向CN2 GIA，测试IP延迟稳定在50ms左右。

**联通9929（CUII/AS9929）**：联通精品网络，回国延迟和稳定性不输CN2，电信联通用户体验尤其好。ZoroCloud的美国9929系列，双程9929，晚高峰不拥堵。

**移动CMIN2**：移动的优化线路，媲美CN2 GIA。如果你是移动宽带用户，CMIN2方案是优先选择。

**双链路回程优化（9929+CMIN2）**：同时接入联通9929和移动CMIN2两条回程，三网用户都能拿到不错的体验。ZoroCloud的US-Titan系列就是这个配置，而且可以在购买时选择运营商（NTT、GTT、Cogent）。

**国际BGP**：不做大陆优化，大陆访问延迟会高一些，但IP干净，解锁流媒体能力强。英国的住宅IP方案通常走这条线。

### IP属性决定能不能用

**数据中心IP**：传统机房IP，便宜，但在2026年的跨境电商、TikTok、Instagram这类风控严的平台上，容易被识别成机房直接封号。

**原生IP（Native IP）**：数据中心分配的IP，但具备原生属性，归属地是目标国家本地，能解锁Netflix、Disney+、YouTube Premium等流媒体。ZoroCloud的香港CN2GIA和美国9929系列都是原生IP。

**双ISP住宅IP**：来自真实家庭宽带网络的静态IP，在平台识别中被视为普通用户。Scamalytics欺诈值接近0，TikTok账号养号、ChatGPT稳定访问、跨境电商多店铺运营，这类场景下住宅IP的通过率远高于机房IP。ZoroCloud的美国住宅系列和英国BGP系列都是这个类型。
